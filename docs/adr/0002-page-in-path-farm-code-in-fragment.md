# The page goes in the path, the Farm Code in the fragment

Each Perfection Category gets its own page, so a Farm Link has to carry two things: which page and which Farm. We put the page in the path and the Farm Code in the fragment: `/fish#mcnew-farm`. Cloudflare serves the app for every path. We rejected putting both in the fragment (`/#mcnew-farm/fish`). That would let the fragment mean two things, and a Farm Code containing `/` would become ambiguous. With the fragment meaning only "which Farm", the rule from ADR 0001 stays simple: the Farm Code is always in the visible address, so Add to Home Screen works from any page and reopens on that page. Watch out for the web app manifest: a `start_url` that drops the fragment brings back mk-tracker's "installed app opens with no code" bug.
